### 添加友链

如果把互联网看成天空，博客就是天上的星星。友链是星星之间的路，让每颗星都不再是孤岛。

想交换友链的话，按下面的格式发封邮件到 [hi@ntfox.example](mailto:hi@ntfox.example)，互相认识一下。

### 友链格式

```ts
{
    name: 'NTFOX',
    avatar: 'https://你的头像地址',
    url: 'https://你的站点地址',
    description: '一句话介绍'
}
```

收到之后我会把它加到 `src/config.ts` 的 `friendLinkConfig` 里。
