### Add a Link

If the internet is the sky, blogs are the stars in it. Link exchanges are the roads between them, so no star stays an island.

To swap links, send an email to [hi@ntfox.example](mailto:hi@ntfox.example) in the format below and say hi.

### Format

```ts
{
    name: 'NTFOX',
    avatar: 'https://your-avatar-url',
    url: 'https://your-site-url',
    description: 'One-line intro'
}
```

Once I get it, it goes into `friendLinkConfig` in `src/config.ts`.
