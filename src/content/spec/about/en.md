
## About

This is Cheng's static site — a home for practice projects and everyday tinkering.

Built with [Astro](https://astro.build/) on a theme adapted from [Momo](https://github.com/Motues/Momo) (MIT).

## Stack

| Layer | What |
| --- | --- |
| Framework | Astro (static site generation) |
| Interactivity | Svelte 5, [swup](https://swup.js.org/) page transitions |
| Styling | Tailwind CSS 4 |
| Search | [Pagefind](https://pagefind.app/) (local index, no external service) |
| Content | Markdown under `src/content/` |
