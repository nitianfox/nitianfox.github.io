
## 关于本站

这里是程的静态网页，用来放练习作品和日常折腾记录。

站点采用 [Astro](https://astro.build/) 构建，主题改造自 [Momo](https://github.com/Motues/Momo)（MIT 协议）。

## 技术栈

| 层 | 用了什么 |
| --- | --- |
| 框架 | Astro（静态站点生成） |
| 交互 | Svelte 5、[swup](https://swup.js.org/) 客户端换页 |
| 样式 | Tailwind CSS 4 |
| 搜索 | [Pagefind](https://pagefind.app/)（纯前端本地索引，无外部服务） |
| 内容 | Markdown，放在 `src/content/` |
